# Retro Auto

Україномовний адаптивний лендинг P2P-оренди класичних автомобілів у Львові.
HTML5, Tailwind Play CDN, окремий `styles.css`, Vanilla JavaScript.

## Лабораторна 9

Форма `#booking-form` містить окремі поля імені, email і телефону,
вибір авто, дату, тривалість, повідомлення та згоду.
Валідація: `assets/js/validation.js`; тести: `tests/validation.test.cjs`.

- Ім’я: 2–100 символів, літери Unicode, пробіли, апострофи, дефіс.
- Email: практичний ASCII-формат із доменом; максимум 150 символів.
- Телефон: строго `+380` і 9 цифр, без автоматичного переформатування.
- Повідомлення: 10–1500 символів після обрізання крайніх пробілів.
- Дата: не раніше сьогодні; тривалість: ціле число 2–24.
- Згода обов’язкова.

Помилки з’являються після взаємодії або submit. Кожне перевірене поле має
текстовий стан та `aria-invalid`. Після успіху відкривається нативний `dialog`,
форма очищається, знімок даних зберігається у видимій чернетці листа.
Закриття: кнопка, Escape або клік поза карткою. Фокус повертається на submit.

**Дані не надсилаються на сервер.** Після перевірки можна вручну відкрити
поштову програму чи скопіювати чернетку. Клієнтська валідація не забезпечує
серверну безпеку. Дані додаються в DOM через `textContent`, без `innerHTML`.

## Запуск і перевірка

Запустіть локальний статичний сервер у цій папці, наприклад:

```sh
python -m http.server 8000
node tests/validation.test.cjs
```

Відкрийте `http://localhost:8000/#booking`. Тести охоплюють 36 випадків.
У браузері перевірено помилки, успіх, reset, чернетку, Tab, Shift+Tab, Escape,
повернення фокусу та відсутність переповнення на ширинах 375 і 768 px.
